# دليل إعداد إرسال رسائل الواتساب

## الخيارات المتاحة لإرسال رسائل التحقق:

### 1. WhatsApp Business API (الأفضل للإنتاج)
**المميزات:**
- رسمي من فيسبوك
- موثوق وآمن
- يدعم القوالب المعتمدة

**خطوات الإعداد:**
1. إنشاء حساب Facebook Business
2. التقدم للحصول على WhatsApp Business API
3. إنشاء قوالب الرسائل وانتظار الموافقة
4. الحصول على Access Token و Phone Number ID

**التكلفة:** متغيرة حسب عدد الرسائل

### 2. Twilio WhatsApp API
**المميزات:**
- سهل الإعداد
- دعم فني ممتاز
- واجهة برمجية بسيطة

**خطوات الإعداد:**
1. إنشاء حساب Twilio
2. تفعيل خدمة WhatsApp
3. الحصول على Account SID و Auth Token
4. إعداد رقم الواتساب

**التكلفة:** $0.005 لكل رسالة تقريباً

### 3. خدمات محلية سورية
**المميزات:**
- دعم محلي
- أسعار مناسبة للسوق السوري
- سهولة التعامل

**أمثلة على الخدمات:**
- SyriaTel Business API
- MTN Syria Business Solutions
- خدمات SMS محلية أخرى

### 4. MessageBird
**المميزات:**
- دعم عالمي
- أسعار تنافسية
- واجهة سهلة الاستخدام

## إعداد متغيرات البيئة:
1. انسخ `.env.example` إلى `.env`
2. أضف مفاتيح API الخاصة بك
3. أعد تشغيل الخادم
